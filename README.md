# ⚔️ Clash of Clans Fan Website

> **Build. Defend. Conquer.**

A multi-page fan website dedicated to the world of **Clash of Clans**, built as a first HTML project. Explore troops, spells, heroes, and join the community — all from one place.

---

## 🌐 Live Site

👉 [priyambhattacharya2006.github.io/first-htmlproject](https://priyambhattacharya2006.github.io/first-htmlproject/)

## 📄 Pages

| Page | Description |
|------|-------------|
| **Home** | Welcome page with the Clash of Clans banner and introduction |
| **Troops** | Table of ground troops (Barbarian, Archer, Giant, Wizard, Dragon) with descriptions and images |
| **Spells** | Overview of available spells |
| **Heroes** | Dedicated page for Clash of Clans heroes |
| **Join** | Contact/join page for clans |

## 🛠️ Built With

- **HTML5** — page structure and content
- **CSS** — styling and layout
- Navigation links across all pages for easy browsing
